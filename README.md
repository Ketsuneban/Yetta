# Yetta

**Текущий тестовый релиз: [0.4.0-preview](https://github.com/Ketsuneban/Yetta/releases/tag/v0.4.0-preview).**

**Yetta** — открытый инструмент персонализации Windows, разрабатываемый поэтапно. **0.4.0-preview** добавляет семь типов предупреждений DAX, 50 пользовательских иконок и курсоры, защищённый TTY-ключ, локальные записи решений и **ограниченную проверку только выбранных через Yetta EXE-файлов** (SHA-256, Authenticode, Microsoft Defender). Полноценный DAX-брокер ADMIN/SYS и восстановление Windows ещё не реализованы.

**Сайт:** https://yetta.pages.dev/ · **Исходный код:** https://github.com/Ketsuneban/Yetta · **Связь:** invzum@gmail.com

## Скачать EXE

**[GitHub Releases — Yetta.exe](https://github.com/Ketsuneban/Yetta/releases/tag/v0.4.0-preview)**

На странице релиза откройте **Assets → YettaSetup.exe** для установки или **Yetta.exe** для портативного запуска. Это отдельный исполняемый файл **для Windows 11 x64**, не ZIP. Он публикуется только после успешной автоматической сборки и проверок ядра. Для запуска отдельный .NET Runtime не нужен.

Проверьте хеш файла по `SHA256SUMS.txt`, опубликованному рядом с EXE. Это **не цифровая подпись**. В этой версии подписанного установщика нет. **Если антивирус блокирует файл, не отключайте защиту и не добавляйте его в исключения**: сообщите о проблеме в [Issues](https://github.com/Ketsuneban/Yetta/issues).

## Что работает в 0.4.0-preview

| Раздел | Возможности |
|---|---|
| **Главная** | Версия, активный профиль Yetta, реальное состояние DAX |
| **Информация** | Версия программы, разрешения текущего процесса, профиль доступа, ОС, пользователь, архитектура, CPU, .NET, время работы, путь настроек |
| **Консоль** | **Marvine:** безопасные команды Yetta; **Windows Terminal и Windows PowerShell:** визуальные вкладки со встроенным текстовым хостом реального PowerShell без повышения прав (при USER и явном согласии); это не полный ConPTY/Windows Terminal |
| **DAX Guard** | Установка/применение логических Guest, Safe User и User; DPAPI-защищённый 64-символьный TTY-ключ с копированием и перевыпуском. ADMIN/SYS не предоставляют настоящих полномочий |
| **DAX Logs** | Локальный журнал фактических решений и событий процессов, запущенных через Yetta, с ограничением размера |
| **DAX Recovery** | Информационный раздел, в который ведёт кнопка «Сброс» смертельного предупреждения; автоматический откат Windows ещё не реализован |
| **Центр активности** | Локальные уведомления (максимум пять одновременно), история текущей сессии, настройка звука |
| **DAX Process** | Выбор EXE, SHA-256 и статус подписи, проверка Defender по запросу, осознанное подтверждение запуска, наблюдение за деревом процесса через WMI; дополнительная проверка SHA-256 через VirusTotal по ссылке |\n| **Настройки** | Темы Fluent/Liquid Glass, статус системного размытия, тестовый просмотр семи типов предупреждений, локальные предпочтения |
| **Источники** | GitHub, релизы, сайт, Icons8 и контактный адрес |

**ВАЖНО О ДОСТУПЕ:** Guest, Safe User и User пока являются **внутренними политиками Yetta**, а не новыми правами Windows. Windows всегда применяет реальный токен пользователя и ACL. Приложение не может заявить «SYSTEM», если такую возможность не создала и не проверила отдельная защищённая служба. Нет UAC-обхода, системного драйвера и универсальной административной консоли.

Режим Windows Terminal представляет собой **встроенный текстовый интерфейс настоящего PowerShell**, а не полноценный ConPTY/Windows Terminal. Windows PowerShell с админ-правами будет доступна только после отдельной реализации безопасного уровня Administrator через штатные средства Windows.

## Данные и конфиденциальность

Настройки находятся в `%LOCALAPPDATA%\\Yetta\\settings.json`. TTY-ключ хранится отдельно, защищённым DPAPI-файлом `%LOCALAPPDATA%\\Yetta\\security\\tty-key.dpapi`; другие приложения с доступом к тому же пользовательскому токену могут попытаться прочитать его. Журнал фактических предупреждений и событий DAX — в `%LOCALAPPDATA%\\Yetta\\dax-logs.jsonl`. История Marvine и Центра активности хранится только в оперативной памяти. Данные устройства не отправляются Yetta на сервер. При добровольном открытии VirusTotal в браузер передаётся хеш выбранного файла; автоматической загрузки EXE нет.

**Безопасность:** DAX Process не является антивирусом и не гарантирует обнаружение вредоносного ПО. Он использует Microsoft Defender, когда тот доступен; блокирует запуск при ошибке/обнаружении и показывает предупреждение о неподтверждённой безопасности. Мониторинг ограничен программами, запущенными через Yetta, и их наблюдаемыми потомками (периодический WMI-опрос может пропустить кратковременные процессы).

## Исходники и сборка из кода

Нужны **Windows 11 x64**, Git, PowerShell и **.NET 10 SDK**.

```powershell
git clone https://github.com/Ketsuneban/Yetta.git
cd Yetta
.\scripts\prepare-fonts.ps1
dotnet run --project src/Yetta.Desktop/Yetta.Desktop.csproj
```

Скрипт скачивает только **официальный шрифт Inter** и проверяет точный Git blob SHA-1. Бинарные версии Inter не хранятся в репозитории; текст его открытой лицензии хранится в `src/Yetta.Desktop/Assets/OFL-Inter.txt`. Для проверки логики:

```powershell
dotnet run --project tests/Yetta.Core.Smoke/Yetta.Core.Smoke.csproj -c Release\ndotnet run --project tests/Yetta.Security.Smoke/Yetta.Security.Smoke.csproj -c Release
```

Для выпуска самодостаточного EXE:

```powershell
dotnet publish src/Yetta.Desktop/Yetta.Desktop.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -o artifacts/Yetta-win-x64
```

GitHub Actions публикует **Yetta.exe** и установщик **YettaSetup.exe** как отдельные Assets. При первой установке используйте YettaSetup.exe; в дальнейших версиях проверка обновлений доступна в Настройках. Проверяется SHA-256, но полноценная подпись издателя пока отсутствует.

## Встроенная PowerShell и согласие

Перейдите в DAX Guard, установите и примените логический профиль **USER**, затем откройте Консоль → Windows PowerShell или Windows Terminal. Перед первым использованием появится собственное **серое предупреждение Yetta** со статусной иконкой, флажком и кнопкой «Я согласен». Команды выполняются настоящим Windows PowerShell с **обычными правами текущего пользователя**. Это не повышает права, не отключает UAC и может менять пользовательские файлы. При запуске Yetta с административным токеном встроенная оболочка недоступна. Согласие можно отозвать в Настройках.

**Обновления:** кнопка в Настройках проверяет GitHub Releases только по запросу, скачивает новый установщик и сравнивает SHA-256 с `INSTALLER-SHA256.txt`. Перед его запуском требуется подтверждение. Пока нет подписи издателя; опубликованный рядом хеш не аутентифицирует поставщика.

**Liquid Glass:** в Windows 11 build 22621+ запрашивается Desktop Acrylic через DWM. На неподдерживаемых системах, при отключённой прозрачности и в специальных режимах доступен читаемый WPF fallback без настоящего размытия. Apple-подобное оптическое преломление не заявляется. При переключении на Fluent используются непрозрачные поверхности.
