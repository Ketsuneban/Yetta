# Yetta

**Текущий тестовый релиз: [0.7.1-preview](https://github.com/Ketsuneban/Yetta/releases/tag/v0.7.1-preview).**

**Yetta** — открытое приложение для Windows 11 с консолью Marvine и менеджером доступа DAX Guard.

**Сайт:** https://yetta.pages.dev/ · **Исходный код:** https://github.com/Ketsuneban/Yetta · **Связь:** invzum@gmail.com

## Скачать EXE

**[GitHub Releases — Yetta.exe](https://github.com/Ketsuneban/Yetta/releases/tag/v0.7.1-preview)**

**Yetta.exe** запускает полное приложение для Windows 11 x64. Внутри уже есть среда .NET, DAX, Python для Marvine, каталог текстов и установщик профиля администратора. При первом запуске компоненты распаковываются локально. **Yetta Installer** скачивает тот же EXE, проверяет SHA-256 и создаёт ярлыки.

Обновляторы веток 0.3–0.5 находят в релизе совместимые имена \`YettaSetup.exe\` и \`INSTALLER-SHA256.txt\`. Для сборок без встроенного обновлятора запустите Yetta Installer вручную.

## Что работает в 0.7.1-preview

| Раздел | Возможности |
|---|---|
| **Главная** | Версия, активный профиль Yetta, реальное состояние DAX |
| **Информация** | Версия программы, профиль доступа, ОС, пользователь, архитектура, CPU, .NET, время работы, путь настроек |
| **Консоль** | Marvine, подсказки, история команд, палитры, Python и просмотр версий |
| **DAX Guard** | Guest и User, а также установка, выключение и отзыв Administrator через отдельную службу DAX |
| **DAX Logs** | Читаемый список недавних решений и событий |
| **DAX Recovery** | Связь с DAX, запуск модуля и вычисление SHA-256 локальных файлов |
| **Центр активности** | Локальные уведомления (максимум пять одновременно), история текущей сессии, настройка звука |
| **Настройки** | Автообновление, звуки, подтверждение ссылок, Subsy, палитра и размер истории Marvine, локальные предпочтения |
| **Источники** | GitHub, релизы, сайт, Icons8 и контактный адрес |

Чтобы активировать Administrator в DAX Guard, выберите профиль и нажмите «Установить и включить». Yetta использует вложенный установщик службы. Windows запрашивает UAC. Доступ получает учётная запись администратора, которая подтвердила установку. Откройте Yetta и выберите DAX Guard для проверки статуса, выключения или отзыва профиля. При активном Administrator в боковом меню доступен раздел «Для разработчиков».

Служба работает под LocalService с собственным SID и управляет состоянием профиля в защищённой области реестра. Она принимает только запросы состояния, включения, выключения и отзыва. Для восстановления отозванного доступа требуется повторная установка. Пакет можно удалить через «Установленные приложения» Windows.

### Команды Marvine

Введите `help` для просмотра команд и их цветовой разметки. Подсказки появляются по мере ввода. `marvine open <путь>` меняет рабочую папку сеанса. `snob uninstall` открывает каталог приложений с поиском и фильтрами.

`script run` открывает выбор .py, а `script run "C:\My Scripts\demo.py"` принимает готовый путь. Интерпретатор Python 3 включён в приложение. Скрипт запускается в отдельном окне Subsy с выводом, полем ввода и кнопкой остановки. Для запуска нужны активный профиль Администратор в DAX Guard и DAX на связи. При обычном запуске Yetta скрипт работает с текущими правами пользователя Windows. Существующий повышенный сеанс дополнительно требует отдельного разрешения DAX. Команда `script list` показывает идентификаторы, а `script stop <ID>` завершает выбранный процесс.

**Ctrl+R** открывает поиск по истории, **Enter** в поиске вставляет выбранную команду для редактирования, **Esc** возвращает к черновику. Соседние строки вывода можно выделять вместе.

## Данные и конфиденциальность

Настройки находятся в `%LOCALAPPDATA%\Yetta\settings.json`. Команды Marvine сохраняются в `%LOCALAPPDATA%\Yetta\marvine-history.txt`; ответы и ключи TTY в этот файл не записываются. Данные об устройстве не отправляются на сервер. DAX tray пока не обеспечивает антивирусную защиту и не реализует полный DAX Guard.


## Единый текстовый файл local.json

В корне репозитория доступен [local.json](local.json). Он содержит вместе русские и уже используемые английские тексты Yetta, Tallow, Marvine и DAX. Переключателя языков пока нет.

Начальный каталог включён в Yetta.exe. Тексты автоматически обновляются без перезапуска: Yetta и DAX проверяют файл в GitHub (тег установленной версии) примерно раз в 60 секунд, а локальные изменения отслеживаются файловым наблюдателем. При этом возможна дополнительная задержка кэша GitHub. Существующие кнопки и надписи обновляются, а новые окна читают актуальный словарь. Перекомпиляция не нужна. Если JSON недоступен или повреждён, оба процесса используют встроенную резервную копию. Имена команд, ключи JSON, сетевые протоколы и решения безопасности DAX не зависят от текста.

## Исходники и сборка из кода

Нужны **Windows 11 x64**, Git, PowerShell и **.NET 10 SDK**.

```powershell
git clone https://github.com/Ketsuneban/Yetta.git
cd Yetta
dotnet run --project src/Yetta.Desktop/Yetta.Desktop.csproj
```

Интерфейс использует системный шрифт Windows; отдельная загрузка шрифта не требуется. Для проверки логики:

```powershell
dotnet run --project tests/Yetta.Core.Smoke/Yetta.Core.Smoke.csproj -c Release
```

Полную версию собирает [Windows build](.github/workflows/desktop-build.yml). Сборка проверяет одиночный EXE в чистой папке и сверяет установленный файл с оригиналом.

## Обновления

Yetta проверяет GitHub Releases при запуске и раз в пять минут, если включено автообновление. Ручная проверка доступна в Настройках и через `yetta update`. Команда `yetta download <ID или тег>` поддерживает версии начиная с 0.3.3. Для единого релиза Yetta сверяет оба EXE с SHA-256 из метаданных GitHub, показывает ход загрузки внутри программы и передаёт проверенный файл установщику.

## Тесты предупреждений

Предпросмотр перенесён из Настроек в Marvine: `/test warn`. [Синтаксис и 16 типов причины](docs/warnings/CAUSES.md).

## Команды и палитра

В Marvine слеш необязателен: `yetta update` и `/yetta upd` равнозначны. Алиасы: upd → update, ver → version, dl → download, marv → marvine, colors → colorset. Для Dracula: `marvine colorset dracula`.

Прокрутка вверх приостанавливает слежение за выводом, возврат вниз возобновляет его. Значки Safe Mode/Danger!/Safe описывают контекст подтверждения; Safe Mode появляется только в безопасном режиме Windows.

Издатель предупреждения проверяется через Authenticode средствами Windows. Неподписанные файлы не получают доверенного издателя из CompanyName. У папок показывается владелец, автор Tallow отмечается отдельно.

## Роли компонентов

Tallow — ядро и координатор. DAX — защитник и владелец политики доступа. Yetta — интерфейс. Marvine — консоль. Subsy и менеджер приложений — дочерние модули. В 0.7.1 скрипты наблюдаются раз в секунду; короткие процессы могут быть пропущены. Журнал локальный, с ротацией, без защиты от изменения владельцем. См. SECURITY.md.
