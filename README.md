# Yetta

**Текущий тестовый релиз: [0.5.1-preview](https://github.com/Ketsuneban/Yetta/releases/tag/v0.5.1-preview).**

**Yetta** — открытый инструмент персонализации Windows 11. В Marvine можно выбрать обои, настроить мышь, клавиатуру и эффекты окон. Команда `win` показывает доступные параметры.

**Сайт:** https://yetta.pages.dev/ · **Исходный код:** https://github.com/Ketsuneban/Yetta · **Связь:** invzum@gmail.com

## Скачать EXE

**[GitHub Releases — Yetta.exe](https://github.com/Ketsuneban/Yetta/releases/tag/v0.5.1-preview)**

На странице релиза откройте **Assets → YettaSetup.exe** для установки или **Yetta.exe** для портативного запуска. Это отдельный исполняемый файл **для Windows 11 x64**, не ZIP. Он публикуется после успешной автоматической сборки Yetta и DAX. Установщик включает оба приложения; для портативного запуска требуется скачать **Yetta.exe**, **Yetta.DAX.exe** и **local.json** в одну папку. Для запуска отдельный .NET Runtime не нужен.

Проверьте хеш файла по `SHA256SUMS.txt`, опубликованному рядом с EXE. Это **не цифровая подпись**. В этой версии подписанного установщика нет. **Если антивирус блокирует файл, не отключайте защиту и не добавляйте его в исключения**: сообщите о проблеме в [Issues](https://github.com/Ketsuneban/Yetta/issues).

## Что работает в 0.5.1-preview

| Раздел | Возможности |
|---|---|
| **Главная** | Версия, активный профиль Yetta, реальное состояние DAX |
| **Информация** | Версия программы, разрешения текущего процесса, профиль доступа, ОС, пользователь, архитектура, CPU, .NET, время работы, путь настроек |
| **Консоль** | **Marvine:** справка, версии и ID релизов, обновление, TTY, настройки Subsy/палитры, история, подсказки и Python-скрипты с проверкой прав; **Windows PowerShell:** встроенный текстовый хост без повышения прав (при USER и явном согласии), пока без полного ConPTY |
| **DAX Guard** | Guest и User, а также установка, выключение и отзыв Administrator через отдельную службу DAX |
| **DAX Logs** | Читаемый список недавних решений и событий |
| **DAX Recovery** | Связь с DAX, запуск модуля и вычисление SHA-256 локальных файлов |
| **Центр активности** | Локальные уведомления (максимум пять одновременно), история текущей сессии, настройка звука |
| **Настройки** | Автообновление, звуки, подтверждение ссылок, Subsy, палитра и размер истории Marvine, локальные предпочтения |
| **Источники** | GitHub, релизы, сайт, Icons8 и контактный адрес |

Пакет **YettaDaxAdministratorSetup.exe** из релиза устанавливает службу DAX Administrator. Windows запрашивает UAC. Доступ получает учётная запись администратора, которая подтвердила установку. Откройте Yetta и выберите DAX Guard для проверки статуса, выключения или отзыва профиля. При активном Administrator в боковом меню доступен раздел «Для разработчиков».

Служба работает под LocalService с собственным SID и управляет состоянием профиля в защищённой области реестра. Она принимает только запросы состояния, включения, выключения и отзыва. Для восстановления отозванного доступа требуется повторная установка. Пакет можно удалить через «Установленные приложения» Windows.

### Команды Marvine

Команда `win mouse-speed` показывает текущую скорость указателя, а `win mouse-speed 12` устанавливает новую. Аналогично работают `win key-delay 1`, `win key-speed 24`, `win animations off` и `win drag-content on`. После изменения Marvine показывает команду возврата прежнего значения. Для записи нужен профиль Пользователь или Администратор. `win wallpaper` открывает выбор изображения для всех мониторов. `win open colors` открывает системные настройки цветов. Полный список разделов доступен через `win open`.

`script run` открывает выбор .py, а `script run "C:\My Scripts\demo.py"` принимает готовый путь. Нужны установленный Python 3, активный профиль Администратор в DAX Guard и DAX на связи. При обычном запуске Yetta скрипт работает с текущими правами пользователя Windows. Существующий повышенный сеанс дополнительно требует отдельного разрешения DAX. Команда `script list` показывает идентификаторы, а `script stop <ID>` завершает выбранный процесс.

**Ctrl+R** открывает поиск по истории, **Enter** в поиске вставляет выбранную команду для редактирования, **Esc** возвращает к черновику. Соседние строки вывода можно выделять вместе.

## Данные и конфиденциальность

Настройки находятся в `%LOCALAPPDATA%\Yetta\settings.json`. Команды Marvine сохраняются в `%LOCALAPPDATA%\Yetta\marvine-history.txt`; ответы и ключи TTY в этот файл не записываются. Данные об устройстве не отправляются на сервер. DAX tray пока не обеспечивает антивирусную защиту и не реализует полный DAX Guard.


## Единый текстовый файл local.json

В корне репозитория доступен [local.json](local.json). Он содержит вместе русские и уже используемые английские тексты Yetta, Tallow, Marvine и DAX. Переключателя языков пока нет.

При установке `local.json` копируется рядом с `Yetta.exe` и `Yetta.DAX.exe`. Тексты автоматически обновляются без перезапуска: Yetta и DAX проверяют файл в GitHub (ветка `main`) примерно раз в 60 секунд, а локальные изменения отслеживаются файловым наблюдателем. При этом возможна дополнительная задержка кэша GitHub. Существующие кнопки и надписи обновляются, а новые окна читают актуальный словарь. Перекомпиляция не нужна. Если JSON недоступен или повреждён, оба процесса используют встроенную резервную копию. Имена команд, ключи JSON, сетевые протоколы и решения безопасности DAX не зависят от текста.

## Исходники и сборка из кода

Нужны **Windows 11 x64**, Git, PowerShell и **.NET 10 SDK**.

```powershell
git clone https://github.com/Ketsuneban/Yetta.git
cd Yetta
dotnet run --project src/Yetta.Desktop/Yetta.Desktop.csproj
```

Интерфейс использует системный шрифт Windows; отдельная загрузка шрифта не требуется. Для проверки логики:

```powershell
dotnet run --project tests/Yetta.Core.Smoke/Yetta.Core.Smoke.csproj -c Release
```

Для выпуска самодостаточного EXE:

```powershell
dotnet publish src/Yetta.Desktop/Yetta.Desktop.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -o artifacts/Yetta-win-x64
```

GitHub Actions публикует **Yetta.exe** и установщик **YettaSetup.exe** как отдельные Assets. При первой установке используйте YettaSetup.exe; в дальнейших версиях проверка обновлений доступна в Настройках. Проверяется SHA-256, но полноценная подпись издателя пока отсутствует.

## Встроенная PowerShell и согласие

Перейдите в DAX Guard, установите и примените логический профиль **USER**, затем откройте Консоль → Windows PowerShell или Windows Terminal. Перед первым использованием появится собственное **серое предупреждение Yetta** со статусной иконкой, флажком и кнопкой «Я согласен». Команды выполняются настоящим Windows PowerShell с **обычными правами текущего пользователя**. Это не повышает права, не отключает UAC и может менять пользовательские файлы. При запуске Yetta с административным токеном встроенная оболочка недоступна. Согласие можно отозвать в Настройках.

**Обновления:** Yetta проверяет Atom-ленту GitHub Releases при запуске и затем раз в пять минут, если включена соответствующая настройка. Ручная проверка доступна в Настройках и через `/yetta update`; `/yetta download <ID>` принимает числовой ID GitHub либо тег релиза. Установщик проверяется по SHA-256 из `INSTALLER-SHA256.txt`. Для ручной установки требуется подтверждение. Не используйте preview-обновления на критических системах до появления доверенной подписи релизов.

## Команды и палитра

В Marvine слеш необязателен: `yetta update` и `/yetta upd` равнозначны. Алиасы: upd → update, ver → version, dl → download, diag → diagnostics, marv → marvine, colors → colorset. Для Dracula: `marvine colorset dracula`.

Прокрутка вверх приостанавливает слежение за выводом, возврат вниз возобновляет его. Значки Safe Mode/Danger!/Safe описывают контекст подтверждения; Safe Mode появляется только в безопасном режиме Windows.

Издатель предупреждения проверяется через Authenticode средствами Windows. Неподписанные файлы не получают доверенного издателя из CompanyName. У папок показывается владелец, автор Tallow отмечается отдельно.
