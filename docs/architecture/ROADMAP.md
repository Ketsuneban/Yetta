# Yetta roadmap

Completed preview foundation: WPF interface, Marvine workspace and Subsy Python sessions, common DAX operation policy, LocalService grant installation/revocation, passive process observation, bounded local audit, verified SHA-256 downloads, installer and Windows CI smoke tests.

Next milestones:
- Dedicated Tallow orchestration services independent of MainWindow.
- Hardened per-operation privileged broker and independent security review before System.
- Event-driven process tracking and explicit coverage diagnostics.
- Authenticode release signing and independently signed update metadata.
- Scenario tests on standard and administrator accounts, multiple DPI and accessibility configurations.

DAX Recovery is deferred by owner instruction. No recovery changes are included in 0.7.0.
