# Yetta 0.3.14-preview — DAX tray companion (installer fix)

- DAX is packaged as an independent background tray application alongside Yetta.
- Six owner-provided tray icons for checking, healthy, alert, threat, disabled and fatal states.
- Tray menu: Check, Restart, Disable, Enable and Exit; left click opens Yetta or its alert details.
- Local DAX readiness check and blocking recovery screen when Yetta cannot communicate with DAX.
- Built-in Windows notification for current component availability.
- **Fixed:** The installer now installs both `Yetta.exe` and `Yetta.DAX.exe`. The previous v0.3.13 installer did not include the companion; please use v0.3.14 instead.

**Preview limitations:** DAX is not yet a malware detector, Defender integration, privileged service or verified OS-recovery engine. Restart applies only to the present user-mode companion. Health reports are limited to observable process/file state and must not be interpreted as complete security scans. The release is unsigned; do not disable antivirus protections.

For a standalone portable installation, download both EXE files into the same directory. The installer is recommended.
