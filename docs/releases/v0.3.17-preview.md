# Yetta 0.3.17-preview — тексты в реальном времени

После обновления `local.json` в ветке **main** GitHub новые надписи появляются в запущенной Yetta и DAX без перезапуска.

- Файл проверяется автоматически примерно раз в минуту (дополнительная задержка возможна из-за кэширования GitHub).
- Локальные изменения в `local.json` отслеживаются и применяются непосредственно после сохранения.
- Открытые окна, кнопки, предупреждения и меню DAX обновляют статические надписи без сброса введённых данных и выбранных опций.
- Каталог скачивается по HTTPS с проверкой размера, структуры и всех обязательных ключей. При ошибке сохраняется последняя исправная версия. Копия сохраняется рядом с программой атомарно, если папка доступна для записи.
- Изменения текста **не влияют** на внутренние команды, каналы связи, защитные политики и права Windows.

**Ограничения:** Не все строки, уже встроенные в составные сообщения, заменяются мгновенно; новые экраны и уведомления всегда используют свежий текст. Необходим интернет для получения новых коммитов. Для первой установки функции потребуется обновление программы до этой версии. Полноценный движок защиты DAX остаётся в разработке.
