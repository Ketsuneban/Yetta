# Yetta 0.3.24 Preview

Исправлена ошибка `403 (rate limit exceeded)` при проверке обновлений. Yetta использует публичную Atom-ленту GitHub Releases для автоматической и ручной проверки. Опрос выполняется при запуске и затем раз в пять минут. Загрузка установщика по-прежнему проверяет SHA-256 по файлу релиза.

Команда `/yetta version` сохраняет числовые ID GitHub, когда API доступен. При ограничении API она показывает последние релизы из ленты с тегами вместо числовых ID. Команда `/yetta download` принимает и числовой ID, и тег вида `v0.3.24-preview`.

В этой версии не изменены полномочия DAX и системные функции. Встроенный PowerShell пока остаётся текстовым хостом, а не полноценным ConPTY.
