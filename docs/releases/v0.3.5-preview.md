# Yetta 0.3.5-preview — одно скруглённое стеклянное окно

- Удалена **внешняя прямоугольная рамка** окон DAX и согласия. Теперь окно не имеет стандартной системной шапки: видна только одна скруглённая стеклянная поверхность.
- Углы окон действительно прозрачны (попиксельная прозрачность WPF). Стеклянная подложка полупрозрачная, так что под ней частично виден интерфейс.
- Окно можно перемещать за заголовок.
- Кнопки «Закрыть», «Отмена», «Я согласен» и галочка подтверждения остаются вне области прокрутки текста.

## Важное техническое ограничение

Режим WPF `AllowsTransparency` даёт прозрачные пиксели и скруглённый внешний контур, **но не обеспечивает аппаратное размытие или оптическое преломление фона**. Настоящее DWM Acrylic нельзя просто наложить поверх такого layered-окна; его нужно реализовать отдельным совместимым механизмом. Этот релиз устраняет именно двойную рамку и непрозрачную прямоугольную подложку.

## Обновление

Настройки → Проверить и обновить в версии 0.3.4-preview либо `YettaSetup.exe` из GitHub Releases. Все изменения остаются в рамках прав текущего пользователя.
