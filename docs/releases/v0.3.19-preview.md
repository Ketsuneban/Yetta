# Yetta 0.3.19-preview — исправление иконок

Исправлен набор иконок после переработки окон предупреждений в 0.3.18.

- **Курсор снова стрелка.** В наборе есть два источника иконок: атлас (где ячейки 1–20 — интерфейсные символы: терминал, инфо, шестерёнка, дом, **стрелка-курсор**, крестик закрытия) и отдельные PNG, где под теми же номерами лежат иконки файлов. В 0.3.18 загрузчик был переведён на PNG целиком, из-за чего курсор стал красным монитором.
- **Боковое меню вернулось к прежним значкам:** обзор — дом, информация — «i», консоль — терминал, журналы — сервер, активность — конверт, восстановление — экспорт, настройки — шестерёнка.
- **Кнопка закрытия** окна предупреждения снова показывает крестик, а не зелёный монитор.
- **Иконки предупреждений** (причина, состояние, верхняя зона) остаются крупными и чёткими: числа 21–50 берутся из отдельных PNG высокого разрешения (48–384 px), а 1–20 — из атласа, где они совпадают с задуманным набором.
- **Показ TTY-Ключа:** кнопка «Показать» теперь с иконкой глаза, «Скрыть» — с перечёркнутым глазом (раньше было наоборот).

**Ограничения:** оформление по-прежнему не даёт прав Windows и не заменяет системный UAC. Кнопка «Сброс» в смертельном окне пока только переходит к восстановлению DAX.
