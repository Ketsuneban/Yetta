# Yetta 0.3.7-preview — несколько открытых предупреждений

Изменено поведение предупреждений по требованию владельца: окна DAX, информационные уведомления и все семь демонстрационных типов из Настроек теперь можно оставлять открытыми одновременно, как окна Проводника. Смертельное окно в демонстрации остаётся поверх других окон. Его кнопка «Сброс» **только открывает DAX Recovery**, не изменяет Windows.

Подтверждения **реальных действий** (скачивание/установка обновления, внешние ссылки, TTY, запуск рискованных команд через Yetta) остаются блокирующими до явного решения пользователя. Некорректное, неподтверждённое действие не выполняется. Кнопки и поле TTY остаются закреплены, текст прокручивается отдельно.

Сохраняются возможности v0.3.6: 50 иконок и курсоры из набора владельца, 7 предупреждений, Windows Credential Manager для 64-символьного TTY, журнал действий и ограниченный мониторинг PowerShell, запущенного через Yetta.

**Не реализованы:** полноценная интеграция Defender, защищённый брокер ADMIN/SYSTEM, полнофункциональная ConPTY и восстановление Windows. Системный Acrylic на части версий Windows недоступен; слой WPF использует отдельный читаемый запасной стиль. Цифровой подписи издателя нет.

Обновление: Настройки → Проверить и обновить или официальный `YettaSetup.exe` из GitHub Releases.
