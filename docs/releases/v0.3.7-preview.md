# Yetta 0.3.7-preview — Windows-style предупреждения

В этом обновлении объединены накопленные правки внешнего вида и новая система оформления предупреждений.

## Предупреждения

- Liquid Glass **отключён только в семи окнах предупреждений**; остальной интерфейс сохраняет выбранную тему.
- Каждое предупреждение имеет сплошной фон по степени риска, прямые углы, контрастный текст и кнопки в центре закреплённой нижней панели.
- Иконка статуса находится в одной горизонтальной строке с иконкой причины и объектом, а не рядом с кнопками.
- Верхняя иконка больше не зависит от типа предупреждения и может задаваться создателем события отдельно через `HeaderIconId`.
- Стандартный чекбокс заменён прямоугольным высококонтрастным элементом со заметной галочкой; подтверждение по-прежнему обязательно для действий, которые его требуют.
- Маленькие статусные значки теперь отображаются как масштабируемые векторные элементы вместо растянутых пикселей 32×32.
- Прокрутка длинного описания, TTY-проверка, функциональность кнопок, аудит и уровни доступа остаются неизменными.

## Основной интерфейс

- Убраны тонкие разделительные линии по краям боковой панели, карточек и других элементов.
- В боковой панели DAX Guard отображается собственный логотип DAX.
- В разделе «Источники» используется новая иконка внешней ссылки, предоставленная владельцем.

## Обновление

В установленной Yetta выберите «Настройки → Проверить и обновить» либо скачайте `YettaSetup.exe` из GitHub Releases.

Функции полноценного DAX runtime, системного ADMIN/SYSTEM и настоящего DAX Recovery по-прежнему не заявляются как завершённые. Изменения в этом релизе относятся к визуальному интерфейсу и не ослабляют проверки разрешений Windows.

Ориентир: Windows/Fluent UI. Точная копия Figma Windows UI Kit не заявляется, поскольку исходный макет недоступен для прямого просмотра без авторизации и не воспроизводится как заимствованный компонент.
