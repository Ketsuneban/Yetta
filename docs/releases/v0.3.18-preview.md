# Yetta 0.3.18-preview — окна предупреждений в стиле Windows 11

Полностью переработан интерфейс всех семи типов предупреждений Yetta: окно теперь повторяет логику и вид системного запроса Windows 11.

- **Стеклянная поверхность.** Окно полупрозрачное (акриловый фон Windows 11, Mica/Acrylic). Если система не поддерживает эффект, окно автоматически становится обычным тёмным — внешний вид не ломается.
- **Верхняя зона:** значок события (что именно задевает предупреждение), причина и кнопка закрытия.
- **Основная зона:** квадратик с иконкой причины (для программ берётся их собственная иконка, иначе — подходящая из набора), название объекта (нажатие открывает поиск в браузере), издатель или путь (нажатие открывает расположение в Проводнике) и прокручиваемый текст без ползунка.
- **Зона соглашения / ключа:** три варианта — только галочка согласия, только поле TTY-Ключа (с показом/скрытием и подсветкой «Ключ совпадает ✔» / «Ключ неверный ✘»), либо галочка, которая после нажатия «улетает» в квадрат и превращается в поле ключа.
- **Зона кнопок:** «Разрешить/Запретить», «Разрешить» недоступна до верного ключа, одиночные «Согласен», «Ок» и «Сброс» для смертельного окна.
- **Квадратик состояния:** потенциальный вред, полная безопасность либо безопасный режим и ограниченный уровень доступа (Гость / Безопасный пользователь).
- **Иконки** теперь поставляются отдельными файлами (1–50), поэтому мелкие значки остаются чёткими, а крупные используют полноразмерные оригиналы.

**Ограничения:** оформление не даёт прав Windows и не заменяет системный UAC. TTY-Ключ по-прежнему защищён Windows Credential Manager. Кнопка «Сброс» в смертельном окне пока только переходит к восстановлению DAX и не сбрасывает Windows.
