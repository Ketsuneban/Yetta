# Yetta 0.2.1-preview — Windows 11

Это исправленный выпуск 0.2.0-preview. Он по-прежнему остаётся тестовым и **не содержит действующих DAX, SYSTEM, TTY, системного редактора или административной консоли**.

## Исправление 0.2.1

- Раздел «Источники» теперь открывает страницу всех GitHub Releases, включая предварительные релизы. Ранее ссылка `releases/latest` не работала, потому что GitHub исключает предварительные релизы из latest.
- На сайте кнопка загрузки ведёт прямо к файлу **Yetta.exe** этого выпуска.
- Номер версии синхронизирован в приложении, документации и интерфейсе.

## Основные изменения 0.2.x

Восемь разделов: Главная, Информация, Консоль, DAX Guard, DAX Logs, DAX Recovery, Настройки, Источники. Встроенная Mavrine выполняет только разрешённые команды; настоящая Windows Terminal запускается отдельно и без повышения прав при логическом профиле User. Для PowerShell Administrator и SYSTEM-профиля безопасность ещё не реализована, поэтому они отключены.

## Скачать

Откройте Assets ниже и выберите **Yetta.exe**. Для Windows 11 x64; .NET устанавливать отдельно не нужно. Дополнительно приложены `SHA256SUMS.txt`, `LICENSE` (MIT) и `OFL-Inter.txt` (SIL OFL 1.1).

Файл пока не подписан цифровой подписью. При предупреждении антивируса не отключайте защиту и не добавляйте Yetta в исключения. Перед работой с системными настройками рекомендуется тестовая Windows Sandbox / виртуальная машина. Никакой привилегированной функциональности в этом выпуске нет.
