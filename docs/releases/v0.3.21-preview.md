# Yetta 0.3.21-preview — системное оформление Windows

Главное окно использует системный шрифт Windows, системные цвета текста и фона, а также выбранный в Windows акцентный цвет. Оформление обновляется при изменении пользовательских настроек Windows. Режим Fluent использует Mica, режим Glass — Desktop Acrylic там, где их поддерживает Windows 11.

Кнопки свернуть, развернуть, восстановить и закрыть используют глифы Segoe Fluent Icons. Фирменные иконки Yetta сохранены. Предупреждения продолжают использовать различимые цвета уровней опасности.

Загрузка Inter больше не нужна для сборки. На системах без доступного DWM-материала интерфейс использует системную палитру без эффекта размытия.
