# Yetta 0.6.0 Preview

Для Windows 11 x64 скачайте **Yetta.exe** для запуска или **Yetta Installer** для установки с ярлыками. Оба варианта содержат один и тот же комплект Yetta. При переходе со старой версии запустите один из них вручную.

- DAX и установщик службы Administrator входят в приложение. В DAX Guard появились карточки возможностей и требований для четырёх профилей.
- Marvine получила стартовый экран с медузой, контекстные подсказки, переключатели параметров и выбор Python-файла. Список команд доступен по `help`.
- Обновления показывают ход загрузки внутри Yetta. Для установки из истории доступны версии от 0.3.3 включительно.
- В интерфейсе можно выделять текст. Окна предупреждений получили компактную полосу прокрутки и чёткую область описания.
