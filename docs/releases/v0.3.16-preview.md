# Yetta 0.3.16-preview — единый local.json

- Русские и существующие английские тексты Yetta, Tallow, DAX и Marvine теперь лежат в одном файле `local.json`.
- Надписи интерфейса, предупреждений, очереди, консоли, профилей и уведомлений используют общий словарь.
- Изменения применяются после перезапуска. При повреждении или отсутствии JSON используется встроенная резервная копия.
- Для портативной версии требуется положить `local.json` рядом с `Yetta.exe` и `Yetta.DAX.exe`; установщик копирует файл автоматически.
- Команды, протоколы, права Windows и проверки DAX остаются в коде, не в пользовательских строках.

**Preview:** Переключения языков нет. Не все сообщения, динамически выдаваемые Windows и сторонними инструментами, редактируются через каталог. DAX остаётся экспериментальным. Релиз не имеет цифровой подписи.
