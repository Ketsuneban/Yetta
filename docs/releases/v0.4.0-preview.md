# Yetta 0.4.0 Preview

- Все предупреждения Yetta проигрывают системный звук критической ошибки. Критический фон тёмно-красный, смертельный чёрный, DAX тёмно-синий, а соглашение серое.
- Главная область, боковая панель, выпадающие списки, консоль и длинные предупреждения показывают мягко размытое содержимое у края, когда дальше есть что прокрутить.
- Marvine Subsy поддерживает прогресс, счетчик шагов, спиннер, подтверждение, ввод текста и цифр, выбор файла, пароль, одиночный и множественный выбор, расширенные ответы, подсказки по мере ввода и страницы.
- Встроенные примеры запускаются командами `/subsy demo` и `/subsy gallery`. Справку, список скриптов и список выпусков можно листать. Скачивание установщика отображает прогресс в консоли.
- Поиск по разделам открывается кнопкой **Найти раздел** или сочетанием `Ctrl+K`. В консоли `Ctrl+L` возвращает фокус в поле команды. В Центре активности и DAX Logs появился поиск.

## Формы Subsy для Python

Запущенный через Marvine скрипт может показать форму строкой в stdout и получить один ответ в stdin. Например:

```python
import json

request = {
    "id": "report",
    "type": "multi",
    "label": "Что включить в отчёт?",
    "options": ["Сводка", "Журнал", "Результаты"],
    "limit": 2,
}
print("@subsy prompt " + json.dumps(request, ensure_ascii=False), flush=True)
reply = json.loads(input())
if reply["value"] is not None:
    print("Выбрано: " + ", ".join(reply["value"]))
```

Типы формы: `confirm`, `text`, `number`, `file`, `password`, `select`, `multi`, `expandable`, `autocomplete`, `pages`. `number` возвращает строку из цифр. `file` возвращает путь, `multi` — массив выбранных вариантов, `pages` — номер страницы с единицы. Отмена передаёт `null`. У `expandable` значения `y`, `n`, `a`, а кнопка справки раскрывает поле `help` в самой форме.

Поле пароля по умолчанию скрыто. Поле `reveal: true` разрешает временно показать ввод. Значение получает указанный в карточке скрипт. Для прогресса доступны `@subsy busy`, `@subsy progress`, `@subsy step` и `@subsy done`.
