# Yetta 0.4.0-preview — предупреждения, TTY и DAX

Семь вариантов: стандартный, предупреждение, опасное, критическое, смертельное, соглашение и DAX. Для каждого задан смысловой цвет и тип иконки, а статус состояния определяется безопасным режимом Windows и логическим уровнем Yetta.

- Все созданные Yetta запросы согласия и сообщения используют единый стеклянный диалог. Текст прокручивается отдельно без видимого ползунка; кнопки закреплены внизу.
- Данные объекта: название с поиском через браузер, путь/издатель с открытием расположения, иконки по типу файла/приложения.
- Согласие: флажок. Для критического подтверждения: TTY 64 знака, поле скрыто символами «•», с переключением видимости и немедленной проверкой; отсутствие проверки блокирует «Разрешить».
- DAX Guard: DPAPI CurrentUser шифрование TTY на диске, создание и перевыпуск, отдельное подтверждение при копировании в буфер. Ключ никогда не записывается в обычные настройки или DAX журнал.
- DAX Logs: реальные записи действий Yetta, а не вымышленные события Defender, по пути `%LOCALAPPDATA%\\Yetta\\dax-events.jsonl`.
- В фатальном предупреждении кнопка «Сброс» переводит в DAX Recovery: никакого автоматического сброса Windows.
- Встроенные ресурсы: комплект из 50 пронумерованных иконок владельца и курсоры №17–20; навигация, заголовок и предупреждения используют новые изображения.
- Для Windows 11 22621+ главное окно пытается включить DWM Mica; при отсутствии поддержки остаётся контрастное Fluent/Glass оформление. Для собственных layered-окон используется локальное размытое отображение содержимого Yetta, а не обещанное глобальное преломление других окон.

**Ограничения:** настоящие привилегии ADMIN/SYS, независимый брокер, мониторинг дочерних процессов, интеграция Defender, ConPTY и системное восстановление ещё не реализованы. TTY не повышает привилегии Windows. Установщик пока не подписан сертификатом издателя; SHA-256 не удостоверяет разработчика.

Установка: Yetta 0.3.5 → Настройки → Проверить и обновить → согласие, либо загрузите `YettaSetup.exe` из GitHub Releases. Настройки сохраняются.
