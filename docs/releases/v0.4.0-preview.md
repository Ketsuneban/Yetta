# Yetta 0.4.0-preview — новая система предупреждений и DAX Process

Предварительный релиз Windows x64. Установщик: `YettaSetup.exe`; портативная версия: `Yetta.exe`.

## Система предупреждений
- Семь категорий: стандартное, предостережение (жёлтое), опасное (красное), критическое (бордовое), смертельное (чёрное), соглашение (серое), DAX (тёмно-синее).
- Иконки из нового архива владельца: 1–50 внутри приложения (панель, предупреждения, статусы, объекты и курсоры с системным fallback). Фактическая иконка EXE подхватывается из Windows при наличии.
- Заголовок, объект, издатель или путь, открытие поиска и проводника, отдельный прокручиваемый текст, закреплённые кнопки. Для критического предупреждения — 64-символьный TTY-ключ со скрытием и проверкой. Галочка согласия видна даже при длинном тексте.
- Сведения о предупреждениях и решениях фиксируются в локальном DAX Logs. Информационные окна могут открываться поверх друг друга; смертельное имеет TopMost. Кнопка «Сброс» **только открывает DAX Recovery**, не сбрасывает Windows.
- Настройки → Предпросмотр предупреждений позволяет вручную проверить семь видов без выполнения опасных действий.

## Безопасность и запуск программ
- В DAX Guard: создание, копирование и перевыпуск TTY-ключа; сохранение в пользовательском DPAPI (не в открытом JSON). Старый ключ перестаёт подходить после перевыпуска. TTY **не заменяет UAC и не выдаёт права ADMIN/SYSTEM**.
- Новый DAX Process запускает только явно выбранные EXE из профиля USER без административного токена. Перед запуском вычисляет SHA-256, проверяет Authenticode и вызывает локальное сканирование Defender при доступности. Нет гарантии обнаружения угроз; сомнительные результаты блокируют запуск, неподтверждённые — требуют отдельного решения.
- Только процессы, запущенные через Yetta, и замеченные WMI-потомки отслеживаются. Включён в том числе встроенный PowerShell. Из-за опроса короткоживущие дочерние процессы могут быть пропущены.
- Необязательный VirusTotal открывается по нажатию и передаёт только хеш в URL.

## Liquid Glass и Windows
- На Windows 11 сборка 22621+ Yetta запрашивает системный Desktop Acrylic через DWM. Является поддерживаемым Windows размытие, но не оптическим преломлением iOS. Если Windows запрещает эффекты прозрачности, в режиме высокой контрастности или на старых сборках используется запасное оформление с читаемым текстом.
- Верхняя панель приложения сохраняет команды окна, всплывающие окна оставляют только один округлый контур.

## Обновление
Настройки → Проверить и обновить. Установка через `YettaSetup.exe` с сохранением настроек `%LOCALAPPDATA%\\Yetta\\`. Выпуск проверяется SHA-256, но **цифровой подписи издателя пока нет**. Не отключайте Microsoft Defender ради запуска этой версии.

## Что по-прежнему не готово
Защищённый ADMIN/SYS-брокер, настоящие системные права по внутреннему профилю, полный ConPTY/Windows Terminal, доказуемое обнаружение всех угроз, восстановление Windows и DAX из резервных копий, подписанный автообновлятор. Эти функции требуют отдельной Windows-инфраструктуры и тестов безопасности и не заявляются как действующие.
