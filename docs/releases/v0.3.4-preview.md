# Yetta 0.3.4-preview — DAX и всплывающие окна Liquid Glass

Исправления по скриншоту:

- Логотип DAX заменён 160×160 PNG с прозрачностью, подготовленным из исходного изображения владельца высокого разрешения (вместо прежних 40×40).
- Окно DAX перестроено: качественный логотип, стеклянные карточки с многослойными полупрозрачными градиентами, мягкими бликами и скруглениями.
- Общая система стеклянных всплывающих окон для DAX и согласия. Текст прокручивается отдельно; кнопки **всегда закреплены снизу**, галочка согласия также остаётся на виду.
- На поддерживаемой Windows 11 запрашиваются системный тёмный заголовок и DWM acrylic backdrop; на остальных версиях сохраняется WPF-оформление.
- При изменении размера окно сохраняет раздельную компоновку текста и кнопок.

## Обновление
В Yetta 0.3.3 откройте «Настройки → Проверить и обновить» и подтвердите установку; либо скачайте `YettaSetup.exe` из Assets релиза.

## Ограничения
«Liquid Glass» здесь реализован как оформление WPF с многослойной прозрачностью и эффектами блика; аппаратное преломление фона не реализовано, DWM backdrop зависит от поддержки Windows. Защищённый runtime DAX и права ADMIN/SYSTEM пока не реализованы. Установщик пока не подписан цифровым сертификатом.
