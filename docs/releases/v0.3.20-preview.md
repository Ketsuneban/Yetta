# Yetta 0.3.20-preview — автоматические обновления

Yetta проверяет GitHub Releases сразу после запуска и каждую минуту, пока программа открыта. При появлении новой версии загрузка начинается автоматически, а системное уведомление Windows 11 показывает ход загрузки и позволяет отменить её. После проверки SHA-256 запускается установщик в тихом режиме.

В настройках можно отключить автоматические обновления. Кнопка ручной проверки и установки остаётся доступной независимо от положения переключателя. Отмена загрузки пропускает эту версию до следующего запуска приложения; следующая версия будет предложена автоматически.

SHA-256 подтверждает целостность относительно файла контрольных сумм в том же релизе, но не заменяет цифровую подпись издателя. Обновление работает, пока запущена Yetta; фоновая служба обновлений не устанавливается.
