# Yetta 0.5.1 Preview

- Marvine получила закреплённую строку ввода, поиск по истории через Ctrl+R, выделение соседних строк и кнопку возврата к последнему сообщению при ручной прокрутке.
- Введите `win`, чтобы увидеть команды для персонализации. Доступны установка обоев, пять параметров мыши, клавиатуры и окон, а также переход к двенадцати страницам настроек Windows. Перед применением параметра Marvine показывает текущее и новое значения.
- `script` показывает справку. `script run` принимает путь или открывает выбор файла. Для обычного запуска Python достаточно активного профиля Administrator и готовности DAX. Интерпретатор наследует права текущего процесса Yetta.
- Установщик Windows x64: **YettaSetup.exe**. Для обновления из Marvine используйте `yetta upd`.
