# Yetta 0.3.25 Preview

Повышена надёжность обновления: установщик сначала сохраняется во временный файл, проходит проверку SHA-256 и только затем заменяет предыдущую проверенную копию. Файл контрольной суммы ограничен по размеру. Ошибки фоновой проверки сохраняются в журнале, а уведомление о них показывается не чаще одного раза за шесть часов.

Менеджер Python-скриптов ограничивает число одновременных процессов и позволяет повторно использовать ID завершённого скрипта. Настройки сохраняются через уникальный временный файл. В сборку GitHub добавлена автоматическая проверка разбора ленты релизов и валидации тегов.

Системные полномочия, антивирус DAX, Maverin и полноценный ConPTY остаются вне этой preview-версии.
