# Yetta 0.2.0-preview — Windows 11

Это предварительный выпуск. Исходный код открыт по лицензии MIT. Доступна **прямая загрузка Yetta.exe** без вложенных ZIP-архивов, установки .NET или установки приложения в Windows.

## Что изменилось
- Восемь разделов: Главная, Информация, Консоль, DAX Guard, DAX Logs, DAX Recovery, Настройки, Источники.
- Главная показывает версию, текущий уровень доступа и состояние DAX.
- Информация показывает действительные права процесса и характеристики устройства.
- DAX Guard: установка и выбор логических Guest, Safe User, User. Уровни Administrator и System пока недоступны.
- Консоль: Mavrine — встроенная консоль с фиксированными командами; Windows Terminal — открытие настоящего терминала обычного пользователя при уровне User; административная PowerShell отключена до реализации защищённого брокера.
- DAX Logs и Recovery — честно обозначенные заглушки.
- Источники: GitHub, сайт, релизы, Icons8, рабочая почта.
- Два интерфейсных оформления, настройки хранятся локально.
- Шрифт Inter под лицензией SIL OFL 1.1, исходный код Yetta — MIT.

## Установка и безопасность
1. Скачайте **Yetta.exe** в разделе Assets этого релиза.
2. Сверьте SHA-256 с приложенным `SHA256SUMS.txt`.
3. Запускайте только на тестовой Windows 11, если проверяете незавершённую версию.

Пока **нет цифровой подписи** и независимого антивирусного аудита. Windows Defender или браузер могут показывать предупреждения. **Не отключайте защиту и не добавляйте Yetta в исключения ради запуска.** Сообщите о блокировке в GitHub Issues.

## Что НЕ работает
Полноценный DAX, аудит процессов, точки восстановления, изменение служб и реестра, привилегированные операции, административная консоль и настоящий SYSTEM-доступ. Установка логического профиля не означает получения Windows-привилегий.
