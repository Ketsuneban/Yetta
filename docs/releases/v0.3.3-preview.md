# Yetta 0.3.3-preview — Исправление окна согласия

Исправлена ошибка, из-за которой при подтверждении обновления кнопка **«Я согласен»** оставалась недоступной, поскольку обязательная галочка оказалась за пределами окна.

- Галочка согласия теперь закреплена непосредственно над кнопками и всегда видна.
- Длинный текст прокручивается отдельно.
- Кнопка «Я согласен» становится активной после установки галочки; без галочки подтвердить действие нельзя.
- Окно допускает изменение размеров и учитывает высоту рабочей области экрана.
- Исправление также распространяется на другие предупреждения согласия Yetta.

## Обновление

В установленной предыдущей версии откройте «Настройки → Проверить и обновить». В окне согласия `0.3.2-preview` галочка может быть скрыта: для установки этого исправления можно скачать `YettaSetup.exe` непосредственно с GitHub Releases и запустить его поверх текущей версии. Настройки сохраняются.

Доступ ADMIN/SYS и системный брокер DAX не реализованы; изменение окна не повышает права Windows. Файлы выпуска проверяются по SHA-256, но пока не подписаны сертификатом издателя.
