# Yetta 0.3.11 Preview

## Предупреждения и DAX

- Разделены три независимых значения предупреждения: верхняя иконка события, иконка объекта-причины и статус безопасности.
- Добавлен явный override `CauseIconId` для логических ID иконок 1–19.
- Смертельное окно использует иконку 48 в шапке и отдельный череп как иконку причины; окно почти чёрное и остаётся поверх остальных.
- Иконка DAX в строке причины загружается из оригинального логотипа DAX.
- Статусы: зелёный — безопасно, красный — потенциальный риск, синий — Гость/Безопасный пользователь/безопасный режим и смертельное окно.
- Информационные окна не показывают статусный блок и имеют только кнопку подтверждения.
- Все окна предупреждений получили прямоугольную рамку; кнопки нейтральны до наведения, а акцент появляется только при hover.
- Длинные подробности остаются в прокручиваемой области, кнопки и подтверждение всегда находятся в отдельной нижней панели.

## Интерфейс

- Добавлены глобальные стили для нейтрализации стандартных WPF-обводок и focus adorners у текстовых полей, списков, таблиц и прокручиваемых областей.
- Для DataGrid отключены линии сетки.

## Проверки

- Windows x64 build выполняется в GitHub Actions на .NET 10.
- Включены Core smoke tests, компиляция WPF приложения, single-file publish и сборка Inno Setup installer.
- Визуальную проверку на реальной Windows 11 следует выполнить после установки сборки.
