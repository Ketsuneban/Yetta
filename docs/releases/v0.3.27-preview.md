# Yetta 0.3.27 Preview

Исправлено системное уведомление при загрузке обновления: оно остаётся на экране до конца загрузки или отмены, полоса показывает фактический прогресс, а технические шаблоны не попадают в видимый текст. После успешной тихой установки Yetta автоматически запускается снова.

Повторная попытка может использовать уже скачанный установщик после проверки SHA-256. При новой загрузке контрольная сумма вычисляется вместе с записью файла, без второго чтения. Обновления уведомления ограничены изменением процента, чтобы не тормозить загрузку.

Подсветка и область нажатия кнопок повторяют их скругление. Предупреждения приведены к единой компоновке с цветом всего окна по типу события, раскрываемыми подробностями и плавным появлением и закрытием. Убрана растянутая системная стеклянная рамка, которая могла давать тонкие швы в интерфейсе.

Кнопки консоли, экрана DAX, окна ID скрипта и очереди предупреждений получили тот же стиль. Дублирующее меню выбора консоли удалено; оба режима остаются доступны через вкладки.

Окна предупреждений остаются окнами Yetta, а не запросами повышения прав Windows. Системные полномочия, антивирус DAX, Maverin и полноценный ConPTY остаются вне этой preview-версии.
