# Yetta 0.3.28 Preview

- Новая рабочая область Marvine с быстрыми командами, подсказками, строкой ввода рядом с кнопкой и отдельной лентой вывода.
- Subsy обновляет одну карточку на запуск скрипта. Демо доступно командой `/subsy demo`. Для Python используй `print("@subsy progress 40 Подготовка")`, `print("@subsy step 2/3 Проверка")` и `print("@subsy done Готово")`. Обычный вывод отображается как текст.
- Tallow различает состояния DAX и показывает их в интерфейсе и по команде `/dax status`. Встроенная оболочка требует готовности DAX, а настройки и диагностика доступны при сбое связи.
- В DAX Recovery можно проверить связь, запустить локальный модуль и вычислить контрольные суммы файлов. DAX Logs показывает события в читаемом виде. Системное восстановление и антивирусная проверка в эту версию не входят.
- Исправлен вылет при открытии настроек. У кнопок, карточек и меню уменьшено скругление.
