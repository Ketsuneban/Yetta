## Yetta 0.7.0 Preview

- Marvine получила спокойный стартовый экран, отдельную строку рабочей папки с выбором каталога и компактные подсказки.
- Tallow согласует операции с общей политикой DAX. Остановка собственного скрипта доступна при любом профиле.
- Запущенные Python-сеансы подключены к наблюдению за деревом процессов. Закрытие окна освобождает подписки и монитор.
- Отмена WinGet завершает его дерево процессов.
- Локальный журнал ограничен двумя файлами по примерно 4 МБ.
- Тексты загружаются из тега установленной версии.
- Обновлены описание архитектуры, политика безопасности и тесты.

Windows 11 x64. DAX остаётся развивающимся компонентом: опрос дерева процессов может пропускать короткие процессы. System, карантин и восстановление Windows не входят в этот релиз.
