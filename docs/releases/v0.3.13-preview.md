# Yetta 0.3.13-preview — DAX tray companion

Новая экспериментальная мини-программа **DAX** запускается рядом с Yetta и отображается в области уведомлений Windows 11.

### Что нового
- Отдельный процесс `Yetta.DAX.exe` с минимальным интерфейсом в системном трее.
- Шесть предоставленных автором иконок состояний: работа, исправность, сообщение, угроза, отключение и критический сбой.
- Меню трея: **Проверить**, **Перезапустить**, **Отключить**, **Включить**, **Закрыть**.
- Проверка доступности интерфейса Yetta и файлов DAX, результаты выводятся уведомлением Windows.
- При отсутствии связи с DAX интерфейс Yetta временно блокируется и предлагает запустить компонент или открыть официальную страницу восстановления.
- Локальное взаимодействие компонентов через Windows named pipes с ограничением доступа текущим пользователем.
- Установщик содержит и Yetta, и DAX; для портативной версии оба EXE должны находиться рядом.

### Ограничения предварительной версии
DAX tray пока не является антивирусом и не предоставляет системную службу, Defender-интеграцию, защиту от вредоносного ПО, изоляцию процессов, автоматическое восстановление Windows или резервное копирование. Команда «Перезапустить» перезапускает только жизненный цикл координатора, а не ещё не созданные службы. Проверка сообщает только реально доступное состояние компонентов.

Версия предварительная, без цифровой подписи. Не отключайте Microsoft Defender ради её установки. Для корректной работы используйте YettaSetup.exe либо держите два исполняемых файла рядом.
