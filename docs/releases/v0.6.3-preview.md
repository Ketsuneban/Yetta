## Yetta 0.6.3 Preview

- В каталоге `snob uninstall` появился поиск по названию, издателю или ID. Системные, скрытые и MSIX-приложения можно отфильтровать.
- В `help` команды подсвечены зелёным, аргументы жёлтым, потенциально опасные действия красным, а описания серым.
- `marvine open <путь>` меняет рабочую папку сеанса. Поддерживаются абсолютные и относительные пути.
- `script run <путь>` запускает Python в отдельном окне Subsy. В окне доступны текстовый ввод и вывод, формы, индикаторы прогресса и остановка скрипта.

**Windows 11 x64.** Запусти `Yetta.exe` для работы без установки. `Yetta Installer` скачает и установит этот же EXE. В установленной Yetta можно запустить обновление командой `yetta update` в Marvine.
