# Yetta 0.3.22-preview — исправление установки обновлений

Исправлена причина, из-за которой обновление скачивалось, но не устанавливалось: работающий процесс Yetta.DAX удерживал файлы, а тихий установщик отменял операцию. Перед установкой Yetta посылает DAX команду завершения. Установщик при необходимости закрывает блокирующие процессы и сохраняет журнал в `%LOCALAPPDATA%\Yetta\Updates`.

Номера версий в боковой панели и нижней строке теперь берутся из версии установленного EXE. Проверка обновлений также использует версию текущей сборки. Ручная установка и отключение автоматических обновлений остаются в настройках.
