# Yetta 0.4.1 Preview

- Иконка причины во всех предупреждениях соответствует объекту, независимо от типа окна.
- Добавлен отдельный набор из 16 иконок причины; собственная иконка приложения используется только для причины-приложения.
- Кнопки предпросмотра убраны из Настроек. Предпросмотр доступен через `/test warn` в Marvine.
- Пароль, TTY и галочка в предпросмотре включаются независимо. Тестовые окна не выполняют действия с выбранным объектом.

Синтаксис и правила определения причины: [Warning causes](../warnings/CAUSES.md).
