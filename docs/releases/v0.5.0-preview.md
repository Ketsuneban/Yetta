# Yetta 0.5.0 Preview

- Добавлен отдельный установщик **YettaDaxAdministratorSetup.exe**. При установке Windows запрашивает UAC. Профиль предоставляется учётной записи администратора, подтвердившей установку.
- В DAX Guard можно проверить состояние профиля, включить его, выключить или отозвать. После отзыва для повторного предоставления доступа нужно запустить установщик DAX. Служба удаляется вместе с пакетом через «Установленные приложения» Windows.
- В боковом меню при активном Administrator появляется «Для разработчиков». На краях прокручиваемой части меню увеличена область размытия.
- Служба проверяет SID вызывающей учётной записи и выполняет ограниченные операции над состоянием профиля в реестре. Интерфейс Yetta работает с обычными правами. Инструменты разработчика будут добавляться отдельно.
