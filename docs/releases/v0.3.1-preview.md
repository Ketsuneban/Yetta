# Yetta 0.3.1-preview — Центр активности и интерфейс

Тестовая версия Windows 11 x64: `YettaSetup.exe` (установщик) и `Yetta.exe` (портативная версия).

## Новое
- Центр активности: локальная история текущего запуска, анимированные уведомления справа снизу, максимум пять одновременно, звук и кнопка «Подробнее».
- Прокрутка боковой панели и возврат к началу страницы при переключении разделов.
- Все характеристики устройства в одной карточке, видимый путь к папке данных Yetta.
- Согласованные идентификаторы GUEST / sUSER / USER / ADMIN / SYS и более читаемый выбор уровня.
- Консоль переименована в **Marvine**, новые команды `overview`, `activity` и зарезервированная `/snob` (без повышения прав).
- Новая иконка 31 из предоставленного владельцем архива, ссылка на Icons8 и актуализированный сайт.

## Безопасность и ограничения
ADMIN и SYS по-прежнему отключены. Отсутствуют защищённый брокер DAX, мониторинг угроз, автоматический откат Windows и ConPTY. История уведомлений является временной UI-историей, а не журналом DAX. Встроенный PowerShell исполняет команды только с действующими неповышенными правами пользователя. Релизы имеют SHA-256, но пока не подписаны сертификатом издателя.

## Обновление
Откройте «Настройки → Проверить и обновить» в 0.3.0-preview либо скачайте `YettaSetup.exe` из GitHub Releases. Локальные настройки сохраняются в `%LOCALAPPDATA%\\Yetta\\`.
