# Yetta 0.3.12-preview

Предварительное обновление системы предупреждений Windows 11.

- Исправлены синий статус Agreement, DAX, Guest, SafeUser и Windows Safe Mode, а также маппинг типовых иконок.
- Описания отображаются сразу, прокручиваются без видимой полосы и не сдвигают кнопки.
- Исправлены прямоугольные кнопки, широкие одиночные действия и hover-шаблон.
- Заголовок закрывается собственной иконкой; уточнён текст неизвестного издателя.

**Ограничения:** DAX не является антивирусным движком, SYSTEM-права недоступны, кнопка «Сброс» не восстанавливает Windows и DAX. Не отключайте антивирус для запуска unsigned EXE. Пожалуйста, сообщайте о визуальных дефектах DPI и случайных линиях через Issues.
