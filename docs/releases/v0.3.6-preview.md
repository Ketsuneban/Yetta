# Yetta 0.3.6-preview — предупреждения, новые иконки и DAX Guard

Обновление Windows 11 x64 (с ограниченной поддержкой более старых сборок через WPF fallback).

## Семь вариантов предупреждений
Стандартное, предупреждение, опасное, критическое, смертельное, соглашение, DAX. Используются иконки из нового архива владельца: заголовок, объект, состояние; окно соответствует схеме пользователя и выглядит в тематическом цвете. Длинное описание прокручивается без видимой полосы; кнопки и галочка/поле ключа закреплены. Смертельный тип открывается поверх остальных окон Yetta, кнопка «Сброс» **лишь открывает DAX Recovery** (не сбрасывает Windows). Все окна Yetta на базе прежних MessageBox и согласий переведены на единую систему.

## TTY
В DAX Guard добавлены скрытое отображение 64-символьного токена подтверждения, копирование с отдельным предупреждением и перевыпуск. Токен сохраняется в **Windows Credential Manager** для текущего пользователя (не plaintext settings.json), сверяется без обычного строкового равенства. При копировании ключ попадает в буфер обмена Windows и может остаться в истории. TTY подтверждение **не даёт прав Administrator/SYSTEM** и не заменяет проверок Windows, UAC и отдельного брокера.

## DAX — реальный ограниченный функционал
- Локальный JSONL-аудит пользовательских действий и предупреждений Yetta, без хранения текста команд и ключей.
- Наблюдение только за запущенным через Yetta PowerShell и его дочерними процессами. Для обнаружения дочерних процессов используется периодический опрос; часть короткоживущих процессов может быть пропущена.
- Эвристическое предупреждение перед некоторыми потенциально опасными командами встроенного PowerShell. Это **не антивирус**, не проверка Microsoft Defender и не гарантированная блокировка всех вредоносных операций.

## Оформление
50 номерных иконок из архива пользователя, меню и диалоги обновлены. Glass-тема пытается включить системный Windows 11 DWM Acrylic, когда доступен, и использует затемнённое размытие графического содержимого Yetta за предупреждениями, сохраняя чёткий текст. Старые Windows получают упрощённое оформление. Эффект не воспроизводит физическую рефракцию Apple Liquid Glass.

## Ограничения и безопасность
Настоящий изолированный привилегированный DAX-брокер, полнофункциональный ConPTY/Windows Terminal, Defender-вердикты, автоматическое восстановление Windows и полноценные режимы Administrator/System всё ещё **не реализованы**. Тестовые окна в настройках демонстрационные. Установщик пока без цифровой подписи издателя. SHA-256 проверяет целостность относительно GitHub-манифеста, но не удостоверяет поставщика.

## Обновление
В установленной Yetta 0.3.5-preview: **Настройки → Проверить и обновить**. Либо скачайте `YettaSetup.exe` непосредственно из GitHub Releases. Настройки пользователя сохраняются. После установки проверьте DAX Guard, все примеры предупреждений в Настройках, TTY-ключ и работу скролла.
