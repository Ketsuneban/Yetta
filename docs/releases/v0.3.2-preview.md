# Yetta 0.3.2-preview — Navigation, access selector and window chrome

Три визуальные правки по снимкам интерфейса:

1. Боковая навигация прокручивается колесом мыши, но **без видимого вертикального скроллбара**. В контенте используются узкие скруглённые полосы прокрутки в цветовой схеме оформления.
2. Список профилей DAX Guard получил собственный округлый выпадающий список, затемнённый фон, стрелку, состояния выбора и наведения в цветах текущей темы.
3. Стандартная светлая верхняя строка заменена интегрированной панелью Yetta с логотипом, названием и кнопками свернуть / развернуть / восстановить / закрыть. Перетаскивание окна и изменение размеров сохраняются через штатный WindowChrome.

## Как обновить

В предыдущей версии откройте **Настройки → Проверить и обновить**, подтвердите загрузку установщика. Либо установите `YettaSetup.exe` из Assets этого релиза поверх старой версии.

## Ограничения

Доступ ADMIN и SYS, ConPTY и системный DAX-брокер по-прежнему не реализованы. Изменение дизайна не даёт дополнительных прав Windows. Установщик для Windows 11 x64 не подписан цифровым сертификатом издателя; SHA-256 проверяет целостность относительно манифеста, но не удостоверяет издателя.
