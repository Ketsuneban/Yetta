# Yetta 0.4.3 Preview

- Команды Marvine принимаются со слешем и без него. Поддержаны алиасы и однозначные сокращения: `yetta upd`, `yetta ver`, `yetta dl`, `marv colors dracula`. Пути и текст аргументов не изменяются.
- Ввод обозначается `/`. Консоль следует за новым выводом после перерасчёта размеров. Прокрутка колесом вверх приостанавливает слежение; возврат в самый низ включает его снова. Новые команды и запросы не сбивают выбранную позицию.
- Палитра `dracula` доступна через `marvine colorset dracula` и Настройки; цвета основаны на официальной спецификации Dracula.
- Справа от причины добавлены состояния Safe Mode, Danger! и Safe с предоставленными иконками. У информационных уведомлений состояние отсутствует. Safe Mode определяется Windows, а не профилем Guest.
- Строка издателя проверяет Authenticode через Windows, включая каталожные подписи. Проверка асинхронная, ограничена по времени и отменяется при закрытии окна. Проверяемый файл не запускается. Неподписанные файлы и ошибки проверки отмечаются явно; CompanyName не используется как доказательство.
- Для папок показывается владелец, для компонентов проекта автор Tallow указан отдельно от цифрового издателя.

Проверка подписи отражает результат Windows на момент чтения; она не заменяет DAX-политику или антивирусную проверку. В текущих сборках Yetta/DAX по-прежнему нет подписи издателя — автор проекта и доверенный подписант не смешиваются.
