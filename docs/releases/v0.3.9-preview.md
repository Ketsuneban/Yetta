# Yetta 0.3.9-preview — стандартное предупреждение в стиле Windows

Изменено **только стандартное предупреждение**, по предоставленному скриншоту дизайна UAC Windows.

- Верхняя тёмная панель с независимой от уровня опасности иконкой события и крупным вопросом.
- Средний тёмный блок: оригинальная иконка причины, её название, статус DAX на той же линии, сведения об издателе, ссылка «Подробнее».
- Текст подробностей раскрывается по нажатию и прокручивается внутри своей области; кнопки остаются видимыми.
- Нижняя отдельная затемнённая панель с кнопками «Разрешить» и «Запретить» по центру. Отказ выделен как безопасный выбор по умолчанию.
- Если требуется явное согласие или TTY-ключ, они остаются обязательными, размещаются в фиксированной нижней зоне и не могут быть обойдены через интерфейс.
- Сохранены прежнее поведение кнопок, протоколирование DAX и возможность нескольких информационных окон.
- Остальные шесть типов предупреждений **не переделывались**.

## Лишние линии
Скрыты декоративные 1px-обводки комбобоксов и полей терминала, отключена старая глобальная обводка в обеих темах. На Windows 11 приложение дополнительно запрашивает удаление системной рамки DWM.

## Обновление
Установленная Yetta → Настройки → Проверить и обновить, либо `YettaSetup.exe` из Assets текущего GitHub Release.

## Ограничения
Этот интерфейс напоминает UAC **только визуально**. Он не отображается на защищённом рабочем столе Windows, не заменяет UAC и не выдаёт ADMIN/SYSTEM. Ручная проверка внешнего вида на Windows 11 должна следовать за успешной автоматической сборкой.
