# Yetta 0.3.15-preview — предупреждения Tallow и Центр активности

- До пяти отдельных немодальных предупреждений одновременно. Остальные собираются в шестом окне: можно листать и отклонять запросы, а свободное место открывает полноценный диалог с нужными проверками.
- Смертельное предупреждение закрывает прочие немодальные предупреждения и очищает очередь.
- Повторяющиеся запросы временно подавляются. Клавиша Escape не закрывает предупреждения; сохранены кнопка закрытия и системный Alt+F4.
- Центр активности сохраняет сообщения локально, группирует по источнику и очищает после заданного срока (по умолчанию каждые 24 часа). Это не затрагивает журналы безопасности DAX.
- Щелчок по значку DAX пытается восстановить уже запущенное окно Yetta.
- Добавлены автоматические проверки очереди и хранения уведомлений.

**Ограничения preview:** Разрешение запрошенного действия непосредственно в шестом окне ещё не предусмотрено — для этого используется полноценный диалог после освобождения места. Привилегированный DAX, интеграция Microsoft Defender, автоматическое восстановление Windows/DAX и другие функции из дорожной карты пока не реализованы. Сборка не подписана цифровым сертификатом; не отключайте антивирус для запуска.

Установщик включает Yetta.exe и Yetta.DAX.exe. Для портативного запуска скачайте оба файла в одну папку.
