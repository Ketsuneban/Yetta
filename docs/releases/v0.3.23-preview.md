# Yetta 0.3.23 Preview

Marvine получила команды из первоначального описания: справку с тремя страницами, просмотр версий и ID релизов GitHub, обновление по ID, управление ключом TTY, переключение Subsy и цветов, список и остановку Python-скриптов. Запуск Python-скрипта требует настоящего административного токена Windows, выбранного профиля Administrator и подтверждения DAX.

Консоль теперь сохраняет историю команд, предлагает дополнения, показывает цветные статусы, базовую разметку и HTTPS-ссылки, а также оформляет распознанный прогресс и шаги системными индикаторами. Для PowerShell доступно подтверждение вида `[y/n]` и `[y/n/a/h]`, когда запрос приходит отдельной строкой. Оформление окна учитывает системные цвета Windows и контрастную тему.

Ограничения preview: встроенный PowerShell остаётся текстовым хостом, а не полноценным ConPTY. Часть интерактивных запросов внешних программ может не отображаться. `/snob`, режим SYSTEM, Maverin, антивирус и системный посредник DAX ещё не готовы. Команды Marvine не повышают права Windows.
