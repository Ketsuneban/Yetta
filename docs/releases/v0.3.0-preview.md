# Yetta 0.3.0-preview — installer, consent and embedded PowerShell

**Предварительная тестовая версия для Windows 11 x64.** Не является системой защиты Windows и не имеет привилегированной службы SYSTEM.

## Добавлено

- **YettaSetup.exe** — установщик для текущего пользователя на базе Inno Setup. Устанавливает Yetta в `%LOCALAPPDATA%\Programs\Yetta`, создаёт ярлыки и предоставляет штатное удаление. Не требует автоматического повышения прав.
- **Настройки → Проверить и обновить** — ручная проверка GitHub Releases, скачивание установщика, проверка целостности SHA-256 и запуск установки только после явного согласия.
- **Серое окно согласия** с описанием последствий, флажком и кнопкой «Я согласен». Обычное согласие на пользовательскую PowerShell сохраняется в настройках и может быть отозвано.
- **Иконки статуса 26, 27, 35** из пользовательского набора: потенциально опасное действие, информационное/безопасное действие, безопасный режим Windows.
- **Встроенная консоль PowerShell**: две визуальные вкладки Windows Terminal и Windows PowerShell передают команды реальному `powershell.exe` с действующими правами **неповышенного** пользователя; вывод отображается в Yetta. Встроенный текстовый хост не является полноценным Windows Terminal/ConPTY, поэтому некоторые полноэкранные или интерактивные программы пока не поддерживаются.
- Кликабельная плитка DAX с информацией о проектируемой системе, статусы GUEST/sUSER/USER/ADMIN/SYS.

## Ограничения и безопасность

- Команды в PowerShell могут изменить или удалить файлы самого пользователя — выбирайте их осмотрительно.
- Сеанс PowerShell недоступен при активном профиле Guest/SafeUser и когда сама Yetta запущена с повышенным административным токеном.
- Уровень USER в Yetta — логическая настройка, **не** повышение привилегий Windows.
- **Нет** DAX-брокера, автоматического права ADMIN/SYSTEM, обхода UAC, автономного сканирования угроз, восстановления Windows или защиты от заражения.
- SHA-256 из того же GitHub Release доказывает целостность скачанного файла относительно опубликованного манифеста, **но не является подписью издателя**. Прежде чем выпускать обновления привилегированных компонентов, необходима проверяемая цифровая подпись.
- Предварительные файлы не подписаны. При срабатывании Defender не отключайте защиту и не добавляйте файл в исключения.
