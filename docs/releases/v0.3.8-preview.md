# Yetta 0.3.8-preview — Windows-style warnings

Новая версия объединяет накопленные исправления основного интерфейса и переделку предупреждений.

- Предупреждения больше не используют Liquid Glass: у них непрозрачный фон, прямые углы и контрастный текст. Цвет меняется у всего окна с учётом степени опасности.
- Кнопки расположены по центру нижней закреплённой панели, статус — на одной линии с иконкой причины.
- Верхняя иконка предупреждения задаётся независимо от его степени опасности (`HeaderIconId`).
- Чекбокс подтверждения получил отдельный высококонтрастный квадратный шаблон с чёткой галочкой.
- Иконки статусов 22, 23, 26, 27, 35 отрисовываются масштабируемыми векторными формами, поскольку исходные PNG имеют лишь 32×32 пикселя.
- В боковом меню для DAX Guard используется логотип DAX, а для «Источники» — предоставленная PNG-иконка внешней ссылки.
- Убраны нежелательные тонкие границы на панели навигации, карточках, уведомлениях и в консоли.

**Сохранено:** существующие действия кнопок, проверки TTY, журнал DAX и возможность наложения информационных/демонстрационных предупреждений, добавленная в v0.3.7.

**Обновление:** Настройки → Проверить и обновить либо установщик из GitHub Releases. Настройки пользователя сохраняются.

Это Windows-подобное оформление, а не дословная копия Figma UI Kit: исходный макет напрямую недоступен. Полноценный системный DAX-брокер, повышенные ADMIN/SYSTEM и реальное восстановление Windows в рамках этой визуальной правки не включены.
