# Yetta 0.3.26 Preview

Настройки Yetta стали компактнее: несколько связанных переключателей теперь находятся в одной панели, а все выпадающие списки используют одинаковое оформление Windows 11. Убраны тонкие обводки карточек. Ручная проверка обновлений работает независимо от автоматической загрузки.

Окна предупреждений стали меньше и используют системную рамку Windows 11 без затемнения рабочего стола. Подтверждения опасных действий, ввод TTY-ключа, отказ и переход к восстановлению сохранены. Исправлен текст предупреждения DAX с буквальными `\\n`.

Кастомный курсор удалён. Профиль Safe User объединён с Guest; сохранённые настройки переносятся автоматически. Yetta использует одно оформление, согласованное с цветами Windows, без переключателя тем.

Добавлены копирование сводки об устройстве и быстрый переход в папку локальных данных.

Это обычные окна приложения Yetta, а не запросы повышения прав Windows. Системные полномочия, антивирус DAX, Maverin и полноценный ConPTY остаются вне этой preview-версии.
