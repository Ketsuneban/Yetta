# Yetta Console — Windows Terminal-inspired unified surface (draft)

В рабочей ветке оба прежних режима «Windows Terminal» и «Windows PowerShell»
объединены в **одну вкладку «Windows PowerShell»** внутри общей чёрной
оболочки, визуально приближённой к Windows Terminal на Windows 11.

## Интерфейс

- Верхняя горизонтальная панель вкладок с профилями **Marvine** (внутренние
  команды Yetta) и **Windows PowerShell** (настоящий powershell.exe).
- Кнопка **+** начинает новую PowerShell-сессию; предыдущая сеcсия
  завершается (пока одновременно работает только одна встроенная PowerShell).
- Стрелка раскрывает список профилей.
- Область вывода имеет чёрный фон, моноширинный **Consolas**, отдельную
  прокрутку и поле ввода. Внутри больше нет старой карточки с тонкой
  прямоугольной рамкой.
- Загрузка PowerShell сохраняет требование согласия пользователя, профиль
  USER и запрет наследования повышенного Windows-токена.

Эта оболочка **пока не является полноценным хостом ConPTY**.
Полноэкранные TTY-утилиты, интерактивные запросы паролей и сложные ANSI
escape-последовательности не заявляются как поддерживаемые.

## Удалённые линии

В XAML убраны фокусные рамки и задана нулевая толщина границ для
ScrollViewer в главной области и боковой навигации. Дополнительно
добавлен глобальный стиль ScrollViewer с прозрачной границей и
отключённой визуальной рамкой фокуса.

## Состояние

Правки сохранены в накопительной ветке. Windows-сборка, визуальная
проверка и релиз не запускались до отдельной команды владельца
**«Скомпилируй»**.
