# Иконки причины предупреждений

| ID / имя PNG и SVG | Причина |
|---|---|
| 1 | Файл, неизвестный формат, файл без расширения |
| 2 | Папка |
| 3 | Программа без собственной иконки, неизвестная программа |
| 4 | Фото |
| 5 | Аудио |
| 6 | Видео |
| 7 | Текстовый файл / документ |
| 8 | Исполняемый файл, скрипт, .bat, .py |
| 9 | Защищённый файл |
| 10 | Облачный файл |
| 11 | Windows 11 (build >= 22000) |
| 12 | PowerShell, командная строка, терминал |
| 13 | Windows 10 и ниже |
| 14 | Архив |
| 15 | Настройки Windows или Yetta |
| 16 | Yetta |
| 17 | DAX |
| 18 | Tallow |

Исходники владельца сохранены в Assets/Causes/*.svg без изменений, PNG подготовлены 384×384 с прозрачностью. Иконки причины независимы от уровня предупреждения и от значков шапки.

Приоритет: облачный placeholder → папка → настройки Windows/Yetta → защита → расширение → неизвестный файл. Категория «важный файл» удалена. Настройки: .reg, системный hosts, .ini/.cfg/.conf/.config/.xml/.json в Windows, каталоге данных Yetta или каталоге приложения. Чужой JSON не получает значок настроек Yetta.

Обычный путь .exe обозначает файл (8). Программа задаётся явно: app:C:\Path\App.exe. У неё используется собственная иконка, при отсутствии — 3; для cmd.exe, powershell.exe, pwsh.exe, wt.exe и WindowsTerminal.exe используется 12.

/test warn <Standard|Information|Caution|Dangerous|Critical|Fatal|Agreement|Dax> <Yetta|DAX|Tallow|Windows|PowerShell|CMD|Terminal|путь> ["текст"] [pass:true/false] [tty:true/false] [check:true/false]

Тест ничего не запускает и не восстанавливает. Пути с пробелами заключаются в кавычки.

Для Fatal используется `/test warn Fatal` без дополнительных аргументов.
